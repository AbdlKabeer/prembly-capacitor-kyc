# prembly-capacitor-kyc

Prembly Capacitor plugin for Ionic apps: the Identity KYC widget, workflows and Transaction Monitoring device signals, with a real device ID read from the phone

## Install

To use npm

```bash
npm install prembly-capacitor-kyc
````

To use yarn

```bash
yarn add prembly-capacitor-kyc
```

Sync native files

```bash
npx cap sync
```
